# Fuentes finales de Misión 01

Estas piezas son las únicas fuentes empaquetadas que el build debe usar para generar los HTML públicos de los niveles aprobados.

- `level1/`: fuente exacta del Nivel 1 antes de aplicar el parche controlado `1/8` + Three.js 0.180.0.
- `level2/`: fuente exacta del Nivel 2 antes de aplicar el parche controlado `2/8` + Three.js 0.180.0.
- `level3/`: fuente exacta ya corregida del Nivel 3 (`3/8`, diagnóstico, reparación y re-medición).

La integridad final se valida contra los SHA-256 documentados en `../AUDIT.md`.
